AudioAuditor bundles an FFmpeg executable and uses it ONLY by invoking it as a
separate program (a child process). AudioAuditor does not link against, statically
or dynamically, any FFmpeg library. Because of this separation, AudioAuditor's own
source code remains licensed under the Apache License 2.0, while the bundled FFmpeg
executable is licensed under the GNU Lesser General Public License, version 2.1 or
later (LGPL-2.1+).

Some FFmpeg builds may include components under the GPL; the build bundled with
AudioAuditor is an LGPL build. If a GPL build is substituted, the bundled binary is
then covered by the GPL.
